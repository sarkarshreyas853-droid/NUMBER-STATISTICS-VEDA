# Task 5: Number Statistics

## Aim
Practise loops, conditions and basic numerical processing in Python.

## What the program does
- Stores a manually created list of 10 numbers.
- Uses a loop and the modulo operator to sort the numbers into even and odd lists.
- Finds the largest and smallest numbers with the built-in `max()` and `min()`.
- Checks that every number was sorted once and that the extremes match the original data.
- Answers the three interview questions.

## Results
| Measure | Value |
|---|---|
| Even numbers | 14, 8, 16, 12 |
| Odd numbers | 7, 23, 41, 3, 29, 35 |
| Largest number | 41 |
| Smallest number | 3 |
